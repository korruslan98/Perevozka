# Платформа пассажирских перевозок

Простой веб-сайт для организации корпоративной развозки сотрудников.

## Возможности

- Регистрация заказчиков (организаций).
- Регистрация перевозчиков (водителей на минивенах).
- Отдельный вход для каждой роли.
- Личный кабинет заказчика:
  - создание заявки на перевозку;
  - указание количества пассажиров;
  - добавление адресов развозки;
  - просмотр своих заявок.
- Личный кабинет перевозчика:
  - лента доступных заказов от всех заказчиков.

## Запуск

Откройте `index.html` в браузере.

Для запуска через локальный сервер:

```bash
python3 -m http.server 8000
```

После запуска откройте:

- http://localhost:8000

## Технические детали

- Проект реализован на чистых HTML/CSS/JavaScript.
- Данные хранятся в `localStorage` браузера.
